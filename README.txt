ONE YEAR ANNIVERSARY WEBSITE — QUICK START

1. Extract this folder.
2. Open the folder in VS Code (File > Open Folder).
3. Add your own images:
   - assets/photos/cover.jpg
   - assets/photos/memory-1.jpg through assets/photos/memory-6.jpg
   Or change the filenames in script.js.
4. Add your music as assets/music/our-song.mp3.
   If your file is named differently, update audio.src in script.js.
5. Personalise the letter by editing the text inside the #letterText section in index.html.
6. Change the anniversary date in index.html if needed.
7. Open index.html in a browser, or use the VS Code Live Server extension and click
   "Go Live".

There is NO photo upload, music upload, or insert button on the website.
You add your media directly into the project folders in VS Code.

The layout is responsive for desktop, tablet, and mobile.
Internet is needed for the Google Fonts; system serif/sans fonts are fallback options.
